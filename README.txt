==============================================================
 SproutS Dashboard - คำอธิบายโครงสร้างโปรเจกต์
 ระบบวิเคราะห์และวางแผนการทบทวนความรู้ (Spaced Repetition)
==============================================================

วิธีใช้งาน
----------
เปิดไฟล์ index.html ด้วยเบราว์เซอร์ได้เลย (ดับเบิลคลิก) ไม่ต้องติดตั้งอะไรเพิ่ม
แต่ต้องต่ออินเทอร์เน็ต เพราะโหลด Tailwind CSS, Chart.js, Lucide Icons
และฟอนต์ Kanit/Inter จาก CDN
ข้อมูลที่ผู้ใช้เพิ่ม/บันทึกจะเก็บใน LocalStorage ของเบราว์เซอร์ (ไม่มีเซิร์ฟเวอร์)

โครงสร้างโฟลเดอร์
-----------------
sprouts-project/
├── index.html          โครงหน้าเว็บ (HTML) และ Modal ทั้งหมด
├── README.txt          ไฟล์นี้
├── css/
│   └── styles.css      CSS และแอนิเมชันที่เขียนเอง
└── js/
    ├── config.js       การตั้งค่า & ค่าคงที่
    ├── data.js         State, ข้อมูลตั้งต้น, CRUD, LocalStorage
    ├── utils.js        สูตรคณิตศาสตร์ & ฟังก์ชันช่วยคำนวณ/จัดรูปแบบ
    ├── chart.js        กราฟเส้น Chart.js & ตาราง Heatmap
    └── app.js          ควบคุม UI, Events, Navigation, การ render หน้าจอ

ลำดับการโหลดไฟล์ (สำคัญ อย่าสลับ)
---------------------------------
ไฟล์ JS ทั้งหมดเป็นสคริปต์แบบธรรมดา (ไม่ใช่ ES Module) ใช้ตัวแปรและฟังก์ชันร่วมกัน
ผ่านขอบเขตส่วนกลาง (global) จึงต้องโหลดตามลำดับนี้:

  1. config.js  (โหลดใน <head> ต่อจาก Tailwind CDN เพราะมีการตั้งค่า Tailwind)
  2. data.js    (ท้าย <body>)
  3. utils.js
  4. chart.js
  5. app.js     (ต้องอยู่ท้ายสุด เพราะมีโค้ดเริ่มต้นระบบ window.onload)

1) index.html  -  โครงสร้างหลัก HTML & Modals
--------------------------------------------------------------
เอาไว้ทำอะไร: เป็นหน้าเว็บหลัก รวมโครงสร้างทั้งหมดที่ผู้ใช้เห็น
มีอะไรบ้าง:
  - <head>: โหลดไลบรารีจาก CDN (Tailwind, Chart.js, Lucide, Google Fonts)
    แล้วเชื่อมไฟล์ config.js และ styles.css
  - Sidebar เมนูด้านข้าง (ย่อ/ขยายได้ และเปิดปิดบนมือถือ)
  - แท็บหน้าจอ 5 แท็บ:
      * home      หน้าแรก สรุปแผนการทบทวนอย่างง่าย
      * dashboard ภาพรวมความจำเชิงลึก (กราฟ, การ์ดวิชา)
      * subjects  รายการวิชาทั้งหมด (ตาราง)
      * forecast  ตารางคาดการณ์ความจำในอนาคต + ตัววางแผนตามเป้าหมาย
      * formula   คู่มือตัวแปรและวิธีคำนวณ
  - Modal ต่างๆ: เพิ่มวิชา, เข้าสู่ระบบ/สมัครสมาชิก, ตั้งเป้าหมาย
    และที่เพิ่มใหม่ใน v2.7: methodModal (ถามวิธีทบทวนก่อนบันทึก),
    offlineModal (สรุป "ยินดีต้อนรับกลับ" หลังปิดเว็บ)
  - หน้าแรกมีปุ่ม "ทบทวนเลยตอนนี้" ในกล่อง "คาดการณ์ความจำในอนาคต" (กดแล้วเด้งไปส่วนบันทึกในภาพรวมเชิงลึก)
  - รองรับมือถือ: เมนูลิ้นชัก + พื้นหลังทึบ, ปุ่มบนหัวเว็บเป็นไอคอนบนจอเล็ก, ตารางเลื่อนซ้าย-ขวาได้
  - ที่แสดงข้อความแจ้งเตือน (Toast container)
  - ท้ายไฟล์: แท็ก <script> เรียก data.js, utils.js, chart.js, app.js ตามลำดับ

3) js/config.js  -  การตั้งค่า & ค่าคงที่
--------------------------------------------------------------
เอาไว้ทำอะไร: เก็บค่าที่ใช้ทั่วทั้งแอปและไม่เปลี่ยนระหว่างทำงาน
มีอะไรบ้าง:
  - tailwind.config     กำหนดสี brand (เขียวชุดต่างๆ) และฟอนต์หลัก (Kanit, Inter)
  - GRADE_MULT          ตัวคูณค่า S ตามระดับการประเมิน
                        (ยาก = 1.2, ปานกลาง = 2.5, ง่าย = 3.25 ตามค่าเริ่มต้นของ Anki)
  - S_MIN               ค่า S ต่ำสุด = 1 ชั่วโมง (ใช้ตอนเลือก "ซ้ำอีกครั้ง")
  - TARGET_R            ระดับความจำเป้าหมายที่แนะนำให้ทบทวน = 0.85 (85%)
  - K_TARGET            ค่าคงที่ = -ln(TARGET_R) ใช้คำนวณระยะเวลาที่ความจำลดถึง 85%
  - INITIAL_S           (ใหม่) ค่า S เริ่มต้นของวิชาใหม่ = 24 ชม. ระบบตั้งให้อัตโนมัติ
  - METHOD_MULT         (ใหม่) ตัวคูณตามวิธีทบทวน: อ่านล้วน 0.65 / อ่านแล้วทำข้อสอบต่อ 0.85 / ทำข้อสอบ 1.0
  - METHOD_LABEL        (ใหม่) ชื่อวิธีทบทวนที่แสดงบนหน้าจอ
  - OFFLINE_MIN_GAP_MIN (ใหม่) ห่างเกินกี่นาทีถึงโชว์สรุปตอนกลับมาเปิดแอป (ค่าเริ่มต้น 10 นาที)

4) js/data.js  -  การจัดการข้อมูล State, CRUD, LocalStorage
--------------------------------------------------------------
เอาไว้ทำอะไร: ศูนย์รวมข้อมูลของแอป และการอ่าน/เขียน/ลบข้อมูล
ตัวแปร State:
  - subjects            รายการวิชาทั้งหมด (มีข้อมูลตัวอย่าง 4 วิชาตั้งต้น)
                        แต่ละวิชามี id, name, category, S, lastReviewedAt, color
                        และอาจมี goal (เป้าหมาย)
  - reviewLogs          ประวัติการทบทวนทั้งหมด (ใช้ทำปฏิทินขีดบันทึก)
  - selectedGrades      ระดับที่ผู้ใช้เลือกไว้ชั่วคราว ก่อนกดยืนยัน
  - currentUser, isAuthSignUp   สถานะการเข้าสู่ระบบ (แบบเดโม)
  - retentionChartInstance      ตัวแปรเก็บกราฟ Chart.js
  - countdownSec        ตัวนับถอยหลัง 30 วินาทีสำหรับรีเฟรชหน้าจออัตโนมัติ
  - plannerSubjectId, plannerGrade, plannerMethod   วิชา/ระดับ/วิธีทบทวนที่สมมติในตัววางแผนเป้าหมาย
  - pendingReview       (ใหม่) คำตอบชั่วคราวในหน้าถามวิธีทบทวน
  - calMonth, calSelected           เดือนและวันที่ที่เลือกในปฏิทิน
ฟังก์ชัน:
  - recordStudySession(subjectId, grade, method)
        บันทึกการทบทวน: คำนวณ S ใหม่ (ตามระดับ x วิธีทบทวน) อัปเดตเวลาทบทวนล่าสุด
        และเพิ่มรายการลงประวัติ (เก็บ method ไว้ด้วย)
  - deleteLog(id)
        ลบขีดบันทึกของวันนี้ แล้วคำนวณค่า S ของวิชานั้นย้อนกลับ
  - deleteSubject(id)
        ลบวิชาพร้อมประวัติการทบทวนของวิชานั้น
  - saveData()
        บันทึก subjects และ reviewLogs ลง LocalStorage
  - loadData()
        โหลดข้อมูลจาก LocalStorage พร้อมกรองข้อมูลที่เสียหายออก
        (เปิดครั้งแรกจะเก็บวิชาตัวอย่างลง LocalStorage ทันที เพื่อให้เวลานับแม่นยำ)
  - saveLastSeen() / loadLastSeen()   (ใหม่)
        เก็บ/อ่าน "เวลาล่าสุดที่เปิดดูแอป" ใช้คำนวณย้อนหลังตอนปิดเว็บ

5) js/utils.js  -  สูตรคณิตศาสตร์ & ฟังก์ชันคำนวณ
--------------------------------------------------------------
เอาไว้ทำอะไร: ฟังก์ชันคำนวณและจัดรูปแบบล้วนๆ ไม่ยุ่งกับหน้าจอ (DOM)
ฟังก์ชัน:
  - calculateRetentionFraction(tHours, S)
        สูตรความจำที่เหลือ R = e^(-t/S) ได้ค่า 0-1
  - getMemoryState(R)
        แปลงค่า R เป็นสถานะ 5 ระดับ (จำได้แม่น / ถึงจุดทบทวนแนะนำ /
        ควรทบทวน / เริ่มลืม / ลืมเกินครึ่ง) พร้อมป้ายสีและคำแนะนำ
  - getElapsedHours(lastReviewedAtISO)
        จำนวนชั่วโมงที่ผ่านไปตั้งแต่ทบทวนล่าสุด
  - getHoursUntilThreshold(S, targetR)
        เวลาที่ความจำจะลดลงถึงระดับที่กำหนด (ค่าเริ่มต้น 85%)
  - formatDurationReadable(hours)
        แปลงชั่วโมงเป็นข้อความอ่านง่าย (ชม. / วัน / เดือน / ปี)
  - getGradeLabel(grade)
        ข้อความแสดงระดับการประเมินพร้อมตัวคูณ
  - formatCountdown(ms)
        แปลงมิลลิวินาทีเป็นข้อความนับถอยหลัง เช่น "อีก 2 วัน 3 ชม."
  - effectiveMultiplier(grade, method)   (ใหม่)
        ตัวคูณจริง = ตัวคูณตามระดับ x ตัวคูณตามวิธีทบทวน (ไม่ต่ำกว่า 1)
  - applyGrade(S, grade, method)
        คำนวณค่า S ใหม่ตามระดับที่ประเมินและวิธีทบทวน (ถ้าไม่ส่ง method = ทำข้อสอบ ตรงกับพฤติกรรมเดิม)
  - cepedaRatio(riHours)
        สัดส่วนระยะเว้นที่เหมาะสมตามงานวิจัย Cepeda และคณะ (2008)
  - buildReviewPlan(subject, goalMs, grade, method)
        สร้างแผนทบทวนทีละรอบจนถึงวันเป้าหมาย
  - fmtDate(ms, withTime)
        จัดรูปแบบวันที่/เวลาแบบไทย
  - dayKey(ms)
        สร้างคีย์วัน (ปี-เดือน-วัน) ใช้จัดกลุ่มข้อมูลในปฏิทิน
  - escapeHtml(str)
        ป้องกัน HTML injection ก่อนนำข้อความไปแสดงบนหน้าเว็บ
  - buildOfflineReport(lastSeenMs, nowMs)   (ใหม่)
        คำนวณย้อนหลัง: R ก่อนปิดเว็บ -> R ตอนนี้ และเวลาที่ถึงจุดทบทวนของแต่ละวิชา
  - formatAwayTime(ms)                      (ใหม่)
        แปลงเวลาที่ห่างหายเป็นข้อความ เช่น "45 นาที" / "14.0 ชม."

6) js/chart.js  -  การวาดกราฟ Chart.js & Heatmap
--------------------------------------------------------------
เอาไว้ทำอะไร: ส่วนแสดงผลที่เป็นภาพกราฟและตารางสีความจำ
ฟังก์ชัน:
  - initChart()
        สร้างกราฟเส้น Chart.js (ตั้งค่าแกน, legend, tooltip)
  - updateChart()

  - renderMemoryHeatmap(containerId)
        วาดตารางสี (Heatmap) คาดการณ์ความจำของแต่ละวิชา
        ณ เวลาต่างๆ ในอนาคต (ตอนนี้ ถึง +1 ปี) คอลัมน์ชื่อวิชาตรึงไว้เวลาเลื่อนบนมือถือ
  - (v2.7) legend ของกราฟย้ายไปด้านล่างและตัวเล็กลงบนจอแคบ

7) js/app.js  -  โค้ดควบคุม UI, Events & Navigation
--------------------------------------------------------------
เอาไว้ทำอะไร: ควบคุมการทำงานของหน้าจอทั้งหมด ผูกปุ่มและฟอร์มเข้ากับข้อมูล
และเป็นไฟล์เริ่มต้นระบบ (ต้องโหลดเป็นไฟล์สุดท้าย)
ฟังก์ชัน แบ่งตามหน้าที่:

  ควบคุมหลัก
  - updateAllViews()       สั่งวาดหน้าจอทุกส่วนใหม่หลังข้อมูลเปลี่ยน
  - switchTab(tabId)       สลับแท็บและเปลี่ยนหัวข้อหน้า
  - openModal / closeModal เปิดและปิด Modal
  - showToast(msg, type)   แสดงข้อความแจ้งเตือนมุมจอ
  - startRealtimeTimer()   นับถอยหลังและรีเฟรชหน้าจอทุก 30 วินาที
  - setMobileSidebar(open) (ใหม่) เปิด/ปิดเมนูลิ้นชักบนมือถือ พร้อมพื้นหลังทึบ
  - updateClock()          นาฬิกาแสดงวันเวลาปัจจุบัน

  การบันทึกการทบทวน
  - selectGrade(subjectId, grade)        เลือกระดับก่อนยืนยัน
  - confirmRecordStudySession(subjectId) กดยืนยัน -> เปิดหน้าถามวิธีทบทวน (ถ้าเลือก "ซ้ำอีกครั้ง" บันทึกทันที)
  - openMethodModal / renderMethodModal  (ใหม่) หน้าถาม: ทำอะไรเป็นหลัก (อ่าน/จำ หรือ ทำข้อสอบ)
                                         ถ้าเลือกอ่าน/จำ จะถามต่อว่าทำข้อสอบต่อไหม แล้วแสดงตัวอย่าง S ใหม่
  - chooseMethodMain / chooseMethodExtra (ใหม่) เลือกคำตอบแบบติ๊ก
  - methodFromChoice(main, extra)        (ใหม่) แปลงคำตอบเป็น read / read_test / test
  - submitMethodModal()                  (ใหม่) ยืนยัน -> recordStudySession(...)
  - navigateToQuickLog()                 เลื่อนไปยังส่วนบันทึกด่วน

  แสดงผลหน้าจอ (render)
  - renderHomeTab()          หน้าแรก: สถิติสรุป (ตัดการ์ด "วิชาของคุณ" ออกแล้วใน v2.7)
  - renderMetrics()          ตัวเลขสถิติในแท็บภาพรวมเชิงลึก
  - renderSubjectCards()     การ์ดวิชาพร้อมแถบความจำและปุ่มประเมิน
  - renderSubjectsTable()    ตารางรายการวิชาทั้งหมด
  - renderForecastList()     รายการวิชาเรียงตามความจำที่เหลือน้อยที่สุด

  เป้าหมายและตัววางแผน
  - renderPlanner()          แสดงแผนทบทวนทีละครั้งจนถึงวันเป้าหมาย
  - renderHomeGoals()        การ์ดสรุปเป้าหมายในหน้าแรก
  - openPlanner(id)          ไปหน้าตัววางแผนของวิชาที่เลือก
  - openGoalModal(id)        เปิดฟอร์มตั้งเป้าหมาย
  - toggleGoalMode()         สลับโหมดตั้งเป้าเป็นวันที่ / ระยะเวลา
  - handleGoalSubmit(e)      บันทึกเป้าหมาย
  - deleteGoal()             ลบเป้าหมาย

  ปฏิทินขีดบันทึก
  - renderReviewCalendar()   วาดปฏิทินรายเดือนพร้อมขีดจำนวนครั้งที่ทบทวน
  - tallyHtml(n)             สร้างขีดสรุปจำนวนครั้งในแต่ละวัน
  - calNav(delta)            เลื่อนไปเดือนก่อนหน้า/ถัดไป
  - calSelect(key)           เลือกวันที่ในปฏิทิน

  ฟอร์มและบัญชีผู้ใช้
  - handleAddSubject(e)      เพิ่มวิชาใหม่จากฟอร์ม
  - toggleAuthMode()         สลับหน้าเข้าสู่ระบบ / สมัครสมาชิก
  - handleAuthSubmit(e)      ส่งฟอร์มบัญชีผู้ใช้ (เดโม ไม่ส่งข้อมูลไปเซิร์ฟเวอร์)

  คำนวณย้อนหลังตอนปิดเว็บ (ใหม่)
  - showOfflineReport(prevSeenAt)   ถ้าห่างเกิน OFFLINE_MIN_GAP_MIN นาที เปิดหน้าสรุป
  - renderOfflineModal(report, prevSeenAt)   แสดง R ก่อน -> หลัง และเวลาทบทวนของแต่ละวิชา
  - initOfflineTracking()           เก็บเวลาที่เปิดดูแอปทุก 5 วินาที (เฉพาะตอนหน้าจอแสดงอยู่)
                                    และตอนสลับแอป/ปิดจอ แล้วสรุปให้ตอนกลับมา

  โค้ดที่ทำงานทันทีเมื่อโหลดหน้า (ท้ายไฟล์)
  - ตัวฟังเหตุการณ์ปุ่มย่อ/ขยาย Sidebar และปุ่มเมนูมือถือ
  - window.onload  เริ่มระบบตามลำดับ: สร้างไอคอน -> โหลดข้อมูล -> อ่านเวลาที่เปิดล่าสุด -> สร้างกราฟ
                   -> เปิดแท็บหน้าแรก -> วาดหน้าจอ -> เริ่มตัวจับเวลา -> สรุปช่วงที่ปิดเว็บ
